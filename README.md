# Самокат, тестовое задание

Кликабельный прототип для тестового задания Самоката (Senior Product Designer, Promo & Media).
Одна корзина с товарами из нескольких магазинов с разным сроком доставки, одна оплата, общие промокод и бонусы.
Прототип показывает сценарий «Ползунок»: клиент сам выбирает, как получить заказ (скорее, стандарт, всё сразу).

**Живая версия:** https://arsenyproduct.github.io/samokat-test/

Сайт публикуется GitHub Actions из ветки `main` по адресу `https://<владелец>.github.io/<репозиторий>/`:
путь берётся из имени репозитория автоматически. Если репозиторий называется иначе, ссылка меняется вместе с ним.

Дизайн: [Figma](https://www.figma.com/design/l6Vm7NcXNe8Z3bRBbuV1zX). Все экраны, тексты, цвета, радиусы и картинки взяты оттуда.

Как пройти: на главной нажмите «Смотреть», дальше «К товарам», любой раздел, откройте Нурофен и комбо,
добавьте их в корзину, нажмите кнопку корзины, «Перейти к оформлению», подвигайте ползунок, «Оплатить»
и подождите 6 секунд на трекинге.

Что важно знать:

- **Цены условные**, как и в макетах. Сумма товаров считается из корзины, стоимость доставки
  для каждого положения ползунка (199, 99 и 0 ₽) взята из фреймов 2.1–2.3.
- В корзине заранее лежат товары Самоката, игрушка из 4 лап и гречка из Ленты. Нурофен и комбо добавляются
  по ходу флоу, после этого корзина совпадает с макетом (2 065 ₽ со скидкой бонусами).
- По умолчанию ползунок стоит на «Стандарт» (в Figma это «Баланс»), как описано в карточке идеи. Выбор запоминается.
- Рейсы считаются по магазинам, которые есть в корзине: если удалить товары магазина, его рейс пропадёт.
- Трекинг нарисован в Figma только для «Стандарт» («Баланс» в Figma). Для «Скорее» и «Всё сразу» заголовки трекинга
  собраны по тем же формулировкам и помечены в `src/data/delivery.ts` как derived.
- На карте только рейсы, которые ещё едут: одна точка, маршрут и курьер на рейс, объединённый рейс рисуется
  по первому магазину.
- «Изменить заказ» одна на весь заказ. Первые 10 секунд трекинга можно менять Шоколадницу (с 4 лапами) и Ленту,
  следующие 10 секунд только Ленту, потом кнопка пропадает. Пока открыты экраны изменения, трекинг стоит на паузе.
- Все тексты, цены и логика ползунка лежат в двух файлах: `src/data/catalog.ts` и `src/data/delivery.ts`.

## Адаптив

- Телефон (окно до 480 px): прототип на весь экран, 100dvh, с учётом safe-area, без рамок и заголовка.
- Десктоп: тёмно-серый фон, по центру устройство 390×844, скролл внутри экрана.
  Если окно ниже 900 px, устройство пропорционально уменьшается.

## Стек

Vite, React, TypeScript (strict), CSS Modules и CSS-переменные из коллекции «Samokat / tokens»
(`src/styles/tokens.css`). Шрифт Onest из Google Fonts, файлы подключены через Fontsource, чтобы не зависеть от сети.
Анимации на CSS и Web Animations API с ease-out, при `prefers-reduced-motion` они выключаются.
Навигация на hash-роутере поверх History API: обновление страницы не даёт 404, кнопка «назад» и системный жест
возвращают на предыдущий экран. Корзина и выбор ползунка сохраняются в sessionStorage.

## Запуск локально

```bash
npm ci
npm run dev        # http://localhost:5173/samokat-test/
npm run build      # проверка типов и сборка в dist/
npm run preview    # собранная версия
```

## Тесты

```bash
npx playwright install chromium   # один раз
npm run test:e2e
```

Тест `tests/flow.spec.ts` проходит весь флоу от главной до задержки на 390×844 и на 1440×900,
проверяет скелетоны, пересчёт ползунка, оплату, задержку, кнопку «назад» и отсутствие ошибок
и предупреждений в консоли. Скриншоты каждого экрана сохраняются в `tests/screenshots/<размер>/`.

## Деплой

`.github/workflows/deploy.yml` собирает проект при пуше в `main` и публикует его на GitHub Pages.
Один раз нужно включить Pages: Settings → Pages → Source: GitHub Actions.
